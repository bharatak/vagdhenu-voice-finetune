# My-Voice Vāgdhenu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fine-tune Vāgdhenu's chant DiT on the user's own Sundarakāṇḍa recordings so it chants in their voice, with every stage built small enough for the user to see, hear and understand.

**Architecture:** A sibling project `myvoice/` holds all new code. The Mac does recording intake, segmentation/labelling, dataset building, a CPU smoke-train and MLX inference. A rented CUDA GPU does only the real fine-tune. Upstream (`../vagdhenu/`) is imported, never edited.

**Tech Stack:** Python 3.12 (`../vagdhenu/.venv`, MLX side), Python 3.10 (`myvoice/.venv-train`, torch 2.4.1 + IndicF5 @ `13f7c4d`), librosa, soundfile, numpy, pytest, macOS `afconvert`, RunPod A100 80 GB.

**Spec:** `myvoice/docs/specs/2026-11-09-own-voice-design.md`

- Never modify anything under `/Users/bharatak/Documents/vagdhenu/vagdhenu/` — import from `vagdhenu/src` via `sys.path`; copy+adapt into `myvoice/` when a change is needed.

- Every task ends with something the user can see or hear (**Checkpoint**) and one thing to explain (**Teach**).

## Review Focus

1. User stumbles, pauses ≥ 3 s and re-chants a line → the earlier attempt is skipped; labels after it do not shift. (Task 3 test `test_align_skips_restart`)
2. A breath/cough mid-hemistich splits one line into two segments → merged back into one clip. (Task 3 test `test_align_merges_split_line`)
3. A short noise burst (door, notification) between lines → skipped, not given a verse's text. (Task 3 test `test_align_skips_noise_burst`)
4. Source text quirks — `।` glued to the next word, `॥५-१-१॥` numbering, a 3-hemistich verse → clean hemistich list. (Task 2 tests)
5. iPhone file is 48 kHz stereo ALAC `.m4a` → intake yields 24 kHz mono WAV of the same duration. (Task 1 test `test_to_wav_24k_mono`)

## Sitting 1 — Mac: from recordings to a dataset, and a training dry-run

### Task 3: Segment a session and align clips to hemistichs

**Files:** Create `mv/segment.py`, `tests/test_segment.py`

**Interfaces:**
- Consumes: `intake.to_wav_24k_mono`, `text.load_sarga`, `Hemistich`.
- Produces:
  - `@dataclass Seg: start: float, end: float` (seconds)
  - `speech_segments(wav: np.ndarray, sr: int, top_db: float = 35, min_gap: float = 0.25) -> list[Seg]` — `librosa.effects.split`, merge gaps < `min_gap`.
  - `@dataclass Clip: hem: Hemistich, start: float, end: float, cost: float`
  - `align(segs: list[Seg], hems: list[Hemistich]) -> list[Clip]`
  - CLI `python -m mv.segment inbox/sarga_NN[_vSS].m4a` → `data/sessions/sarga_NN/{session.wav, clips/<hem.id>.wav, clips.json}`; prints kept/skipped counts and pace (s/syllable).

**Alignment algorithm (DP, decided here):**
- Pace `r` = Σ speech duration / Σ `n_syll` over all hems; re-estimate once from the first pass's accepted clips.
- State `(i, j)` = first `i` hems consumed using first `j` segments. Transitions:
  - **match** hem `i+1` ← segments `j+1 … j+k`, `k ∈ {1,2,3}`; span `D = end(j+k) − start(j+1)`; cost `|ln(D / (r · n_syll))|`.
  - **skip segment** `j+1`: cost `0.3` if the gap after it ≥ 2.5 s (restart protocol), else `0.7`.
  - **skip hem** `i+1` (line not chanted): cost `1.5`.
- Backtrack minimum total cost. Keep a clip only if its match cost < `0.25` (≈ ±28 % duration); others reported as `low_confidence` and not written.
- Clip audio = span padded 0.1 s each side, peak-normalised to −1.5 dBFS.

- [ ] **Step 1:** Tests with synthetic `Seg` lists and hems of known `n_syll` (pace 0.3 s/syll):
  - `test_align_clean`: 4 hems, 4 matching segs → 4 clips in order, all cost < 0.1.
  - `test_align_merges_split_line`: hem 2's audio split into two segs (gap 0.4 s) → one clip spanning both.
  - `test_align_skips_restart`: hem 2 attempted (partial, 40 % length), 3 s gap, then full hem 2, hem 3 → clips for 1,2,3; hem 2 clip starts at the *second* attempt.
  - `test_align_skips_noise_burst`: 0.2 s seg between hems 1 and 2 → not part of any clip; hem 2 correct.
  - `test_speech_segments_tone_bursts`: three 1 s tones separated by 0.6 s silence → 3 segs within ±0.05 s.

- [ ] **Step 5:** Run CLI on the user's first real session; print summary.
